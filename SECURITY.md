# Security and privacy

Data stays in the browser until the user exports it. Browser storage is not encrypted and can be cleared by the browser. Backups are plain JSON and may contain sensitive research information. Do not publish backups, personal interviews, or private source documents in issues or pull requests.

This version has no account system, remote database, or cross-device synchronization. Do not use a shared device for confidential material. For a vulnerability report, contact the maintainer privately through their GitHub profile rather than posting exploit details or research data in a public issue.
