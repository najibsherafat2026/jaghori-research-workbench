# مشارکت

Issues and pull requests are welcome for accessibility, right-to-left layout, data portability, and research workflows. Describe the problem, expected behavior, and how to reproduce it. Run `npm test` before a pull request.

Use invented example names and places in screenshots and tests. Do not submit unpublished interviews, personal contact details, private genealogies, or copyrighted book chapters. Submitting a contribution indicates that you have the right to license that code under the repository's MIT license.
